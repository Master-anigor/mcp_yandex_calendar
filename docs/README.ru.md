# MCP-сервер Яндекс Календаря

Python-интеграция для чтения, создания и удаления событий через MCP и CalDAV. Проект экспериментальный, рассчитан на один аккаунт и локальное либо доверенное окружение. Основная документация, команды запуска и ограничения — в [README](../README.md).

## Пароль приложения

Перейдите в [настройки паролей приложений Яндекс ID](https://id.yandex.ru/security/app-passwords), создайте отдельный пароль для Календаря и сохраните его в локальном `.env`, созданном из `env.example`.

**Не используйте основной пароль аккаунта.** Не публикуйте `.env`, пароль приложения, логи или данные календаря. Для знакомства с проектом используйте отдельный тестовый аккаунт: создание и удаление событий действительно меняют подключённый календарь, который выбирается первым из найденных.

По умолчанию сервер слушает `127.0.0.1:8088`. Для Docker передавайте `MCP_HOST=0.0.0.0` внутрь контейнера, но публикуйте порт только на `127.0.0.1` хоста, как в основном README.

## Проверки

```bash
python -W error::RuntimeWarning -m unittest discover -s tests -v
```

Это 19 изолированных unit-тестов с подменёнными внешними зависимостями. Они не обращаются к Яндексу и не подтверждают работу MCP-транспорта, установку зависимостей или сборку Docker. Полноценная интеграционная проверка ещё требуется.

Обработка часовых поясов, повторяющихся событий и сложного iCalendar пока неполная. Сервис нельзя считать готовым к открытому доступу из интернета.
